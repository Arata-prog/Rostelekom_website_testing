# Тесты авторизации и регистрации Ростелеком

Этот репозиторий содержит автоматизированные тесты для проверки форм авторизации и регистрации на сайте Ростелекома (`b2c.passport.rt.ru`).

## Тестовые сценарии

### Авторизация (`rostelecom/rostelecom_auth_test.py`)

Этот файл включает следующие проверки входа:

1.  **`test_successful_email`**: Проверяет успешный вход пользователя с использованием валидного адреса электронной почты и пароля.
2.  **`test_successful_login`**: Проверяет успешный вход пользователя с использованием валидного логина и пароля.
3.  **`test_failed_login`**: Проверяет, что система корректно обрабатывает попытку входа с невалидными учетными данными и отображает сообщение об ошибке.
4.  **`test_vk_social_login`**: Проверяет, что при нажатии на иконку VK происходит корректный редирект на страницу авторизации VK ID.
5.  **`test_user_agreement`**: Проверяет, что ссылка на пользовательское соглашение открывается в новой вкладке.

### Регистрация (`rostelecom/rostelecom_reg_test.py`)

Этот файл включает следующие проверки регистрации:

1.  **`test_registration_invalid_firstname`**: Проверяет появление ошибки при вводе цифр в поле 'Имя'.
2.  **`test_registration_missing_region`**: Проверяет появление ошибки, если не выбран регион.
3.  **`test_registration_existing_account`**: Проверяет появление модального окна 'Учётная запись уже существует' при попытке регистрации с существующим email.
4.  **`test_registration_invalid_password_format`**: Проверяет появление ошибки, если пароль не содержит заглавной буквы.
5.  **`test_registration_password_mismatch`**: Проверяет появление ошибки, если введенные пароли не совпадают.
6.  **`test_registration_success_attempt`**: Проверяет успешный переход на страницу подтверждения email/телефона при вводе валидных данных.

### Личный кабинет (`rostelecom/rostelecom_lk_test.py`)

Этот файл включает тесты для различных функций личного кабинета (`lk.rt.ru`) и связанной формы "Переезд" (`start.rt.ru/pereezd`):

1.  **`test_service_order_form`**: Тест заполнения формы заказа услуг (Интернет + ТВ).
2.  **`test_service_order_invalid_name`**: Тест: Ввод невалидного имени и проверка сообщения об ошибке на форме заказа услуг.
3.  **`test_support_chat_widget`**: Тест: Открытие чата поддержки и отправка сообщения.
4.  **`test_vk_link`**: Тест: Клик по ссылке VK открывает новую вкладку.
5.  **`test_relocation_form_phone`**: Тест: Ввод региона и номера телефона на форме Переезда и проверка подтверждения.
6.  **`test_relocation_invalid_region`**: Тест: Ввод невалидного региона и проверка ошибки на форме Переезда.
7.  **`test_relocation_empty_phone`**: Тест: Пустое поле телефона и проверка ошибки на форме Переезда.

## Установка зависимостей

Перед запуском тестов установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

## Запуск тестов

Для запуска всех тестов выполните следующую команду в корневой директории проекта:

```bash
pytest -v
```

Или можно запустить тесты только для конкретного файла:

```bash
pytest -v rostelecom/rostelecom_auth_test.py
# или
pytest -v rostelecom/rostelecom_reg_test.py
# или
pytest -v rostelecom/rostelecom_lk_test.py
```
